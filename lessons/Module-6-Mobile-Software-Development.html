06-modul

Mobile Software Development

Kasbiy ingliz tili, texnik fikrlash va hamkorlikdagi yozuv bir darsda.

Dars pasporti

Yo‘nalish
Software Engineering
Format
O‘rganish · Mashq · Yozish
Daraja
A2–B2

Mobil ilova, platforma va foydalanuvchi tajribasi

Daraja Vaqt Yakuniy natija
A2–B290–110 daqiqaMobil ilova konsepsiyasi va asoslangan tanlov

O‘quv maqsadlari

  • mobil mahsulotning asosiy qismlarini tavsiflash;
  • native va cross-platform yondashuvlarni taqqoslash;
  • foydalanuvchi tajribasi va qurilma cheklovlarini tushuntirish;
  • mobil ilova konsepsiyasini taqdim etish.

Warm-up

  1. Telefoningizdagi eng foydali ilova qaysi?
  2. Kichik ekranda dizayn nimasi bilan farq qiladi?
  3. Ilova internet bo‘lmasa ham ishlashi kerakmi?
  4. Android va iOS uchun alohida dastur yaratishning foydasi nima?

Technical vocabulary

Termin Sodda ta’rif Misol
native appan app built for one platformA native app can use device features directly.
cross-platformsoftware working on several platformsCross-platform development can reduce cost.
touch interfacecontrols operated by touchThe touch interface uses large clear buttons.
notificationa short message from an appThe app sends a deadline notification.
permissionapproval to access a device featureThe camera permission must be explained.
battery usageenergy consumed by an appBackground tracking increases battery usage.
offline modefunctions available without internetOffline mode stores unfinished work locally.
usability testingobserving people using a productUsability testing revealed a confusing menu.

Reading

A team designs a campus navigation app. The first version constantly tracks location and quickly drains the battery. It also requests camera access although the feature is unnecessary. During usability testing, students ask for larger map controls and an offline campus map. The team reduces background tracking, removes the camera permission and redesigns the touch interface. The improved version is faster, clearer and more respectful of user privacy.

Comprehension

  1. Which two problems exist in the first version?
  2. What do students request?
  3. Which unnecessary permission is removed?
  4. How does testing improve the product?

Language focus — requirements

  • The app must protect user data.
  • It should provide offline access.
  • It must not request unnecessary permissions.
  • It could include optional notifications.

Darajali topshiriqlar

Beginner — A2

60–80 so‘zda mobil ilovaning foydalanuvchisi va to‘rtta funksiyasini yozing.

Intermediate — B1

100–140 so‘zda native va cross-platform yondashuvni cost, performance va development time bo‘yicha taqqoslang.

Advanced — B2

180–220 so‘zda privacy, offline mode, accessibility va battery usage hisobga olingan mobil mahsulot taklifini yozing.

Wiki writing

Design a useful mobile application for university students.

Kamida 5 ta termin va must / should / could bilan ustuvor talablar yozing.

Peer-review

  • Funksiyalar foydalanuvchi muammosiga mosmi?
  • Maxfiylik va permission tushuntirilganmi?
  • Mobil cheklovlar hisobga olinganmi?
  • Talablar ustuvorligi aniqmi?

Self-assessment

  • Men native va cross-platform farqini tushuntira olaman.
  • Men mobil talablarni ustuvorlik bilan yozdim.
  • Men privacy va battery usage’ni hisobga oldim.
  • Men 5 ta yangi terminni ishlatdim.
