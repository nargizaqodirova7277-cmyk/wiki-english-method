Artificial Intelligence

Kasbiy ingliz tili, texnik fikrlash va hamkorlikdagi yozuv bir darsda.

Dars pasporti

Yo‘nalish
Software Engineering
Format
O‘rganish · Mashq · Yozish
Daraja
A2–B2

AI imkoniyatlari, cheklovlari va mas’uliyatli foydalanish

Daraja Vaqt Yakuniy natija
A2–B280–100 daqiqa120–180 so‘zli tahliliy Wiki matni

O‘quv maqsadlari

Modul yakunida siz:

  • asosiy AI terminlarini kontekstda ishlatasiz;
  • AI vositasining foydasi va cheklovini taqqoslaysiz;
  • sabab va natijani aniq ifodalaysiz;
  • mas’uliyatli foydalanish bo‘yicha fikringizni dalillaysiz.

Warm-up

Juftlikda muhokama qiling:

  1. Siz qaysi AI vositalarini bilasiz?
  2. AI dasturchiga qaysi vazifalarda yordam beradi?
  3. AI javobiga har doim ishonish mumkinmi?
  4. Yakuniy qaror uchun kim javobgar?

Technical vocabulary

Termin Sodda ta’rif Misol
artificial intelligencehuman-like tasks performed by softwareArtificial intelligence can classify data.
machine learningsystems learning patterns from dataMachine learning improves with useful data.
dataseta structured collection of dataThe team cleaned the dataset before training.
promptan instruction given to an AI systemA clear prompt produces a more relevant answer.
outputa result produced by a systemThe developer reviewed the generated output.
biasan unfair or systematic preferenceBiased data can create unfair results.
accuracyhow often a result is correctThe team measured the model’s accuracy.
verificationchecking whether information is correctHuman verification is necessary before release.

Reading

A software team uses an AI assistant to explain unfamiliar code and suggest test cases. The tool saves time, but its suggestions are not always correct. One developer copies an answer without checking it, and the new code creates a security problem. The team changes its process: developers may use AI for ideas, but they must review every output, run tests and record how the tool was used. AI remains useful, while responsibility stays with the human team.

Comprehension

  1. How does the AI assistant help the team?
  2. What problem does the unchecked output cause?
  3. Which three rules does the team introduce?
  4. Who remains responsible for the final result?

Language focus — cause and contrast

Use these connectors:

  • because — The result was unsafe because nobody verified it.
  • therefore — The dataset was incomplete; therefore, the output was inaccurate.
  • however — AI can save time; however, it can make mistakes.
  • although — Although the suggestion looked correct, the developer tested it.

Darajali topshiriqlar

Beginner — A2

60–80 so‘zda AI dasturchiga yordam beradigan ikkita vazifani yozing. prompt, output, verification, developer terminlarini ishlating.

Intermediate — B1

100–140 so‘zda AI vositasining ikkita foydasi va ikkita xavfini taqqoslang. Kamida uchta connector ishlating.

Advanced — B2

160–200 so‘zda quyidagi fikrni muhokama qiling: “AI-generated code should always require human approval.” Dalil va real misol keltiring.

Wiki writing

How can software developers use AI responsibly?

Matn talablari:

  • aniq pozitsiya;

  • kamida 2 ta sabab yoki misol;
  • muvozanatli xulosa.

Peer-review

Sherigingiz matnida tekshiring:

  • fikr aniqmi;
  • foyda va xavf muvozanatlimi;
  • terminlar tabiiy ishlatilganmi;
  • tavsiya amaliymi?

Self-assessment

  • Men 5 ta AI terminini ishlata olaman.
  • Men AI natijasini tekshirish sababini tushuntira olaman.
  • Men fikrimni sabab va misol bilan dalilladim.
  • Men foydalanilgan yordamni ochiq ko‘rsatdim.
