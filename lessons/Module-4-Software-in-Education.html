O‘quv maqsadlari

Modul yakunida siz:

  • educational software terminlarini ishlatasiz;
  • foydalanuvchi ehtiyojini aniqlaysiz;
  • ikki raqamli vositani mezon asosida taqqoslaysiz;
  • ta’lim uchun dasturiy yechim taklif qilasiz.

  1. Darsda qaysi raqamli vositalardan foydalanasiz?
  2. Yaxshi o‘quv dasturi qanday bo‘lishi kerak?
  3. Texnologiya o‘qituvchini almashtiradimi yoki qo‘llab-quvvatlaydimi?
  4. Interneti sust talabaga qanday yechim kerak?

Technical vocabulary

Termin Sodda ta’rif Misol
learning platforman online environment for studyThe learning platform stores course materials.
accessibilityusability for people with different needsCaptions improve accessibility.
user interfacethe visible controls of softwareA simple user interface reduces confusion.
feedbackinformation about performanceImmediate feedback helps students correct mistakes.
progress trackingrecording completed learningProgress tracking shows unfinished activities.
adaptive learningcontent changing to learner needsAdaptive learning provides easier or harder tasks.
offline accessuse without an internet connectionOffline access supports students in remote areas.
engagementactive interest and participationShort activities can improve engagement.

Reading

A university introduces a vocabulary application for engineering students. At first, the app contains attractive animations but long menus and no offline mode. Students with slow internet stop using it. The design team interviews learners and simplifies the interface, adds downloadable lessons and provides short feedback after every task. Usage increases because the revised product solves real learner problems instead of focusing only on decoration.

Comprehension

  1. Why do some students stop using the first version?
  2. How does the team learn about user needs?
  3. Which three improvements are introduced?
  4. What lesson does the project teach about design?

Language focus — comparison

  • more useful than
  • easier to use than
  • as accessible as
  • the most important feature
  • while / whereas

Example: Offline access is more useful than animation for students with weak internet.

Darajali topshiriqlar

Beginner — A2

Sevimli o‘quv ilovangiz haqida 60–80 so‘z yozing. Uning uchta foydali funksiyasini ayting.

Intermediate — B1

Ikki o‘quv vositasini accessibility, feedback va engagement bo‘yicha 100–140 so‘zda taqqoslang.

Advanced — B2

160–200 so‘zda universitet uchun yangi learning platform konsepsiyasini taklif qiling. Turli foydalanuvchilar ehtiyojini hisobga oling.
