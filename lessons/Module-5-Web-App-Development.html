05-modul

Web App Development

Kasbiy ingliz tili, texnik fikrlash va hamkorlikdagi yozuv bir darsda.

Dars pasporti

Yo‘nalish
Software Engineering
Format
O‘rganish · Mashq · Yozish
Daraja
A2–B2

Web-ilovani rejalash va yaratish jarayoni

Daraja Vaqt Yakuniy natija
A2–B290–110 daqiqaWeb-ilova uchun qisqa product proposal

O‘quv maqsadlari

Modul yakunida siz:

  • frontend, backend va database vazifalarini farqlaysiz;
  • web-ilovaning foydalanuvchi muammosini tushuntirasiz;
  • ishlab chiqish jarayonini ketma-ket tasvirlaysiz;
  • sodda product proposal yozasiz.

Warm-up

  1. Har kuni qaysi web-ilovalardan foydalanasiz?
  2. Web-sayt va web-ilova o‘rtasida qanday farq bor?
  3. Foydalanuvchi uchun eng muhim uchta sifat nima?
  4. Mahsulot yaratish kod yozishdan oldin nimadan boshlanadi?

Technical vocabulary

Termin Sodda ta’rif Misol
frontendthe part users see and interact withThe frontend displays the dashboard.
backendserver-side logic and processingThe backend validates the request.
databaseorganized storage for informationThe database stores user profiles.
requirementa needed function or conditionThe team documents every requirement.
prototypean early model of a productUsers tested the prototype before development.
responsive designlayout adapting to screen sizeResponsive design improves mobile use.
authenticationconfirming a user’s identityAuthentication protects private accounts.
deploymentmaking software available to usersDeployment moved the application to production.

Reading

A student team plans a web application for booking university rooms. Before coding, they interview students and administrators. The first prototype shows available rooms, but users also need cancellation and notification features. The team updates the requirements, creates a responsive frontend, connects it to a backend and stores bookings in a database. After testing authentication and mobile layouts, they deploy a small pilot version. Early feedback prevents the team from building unnecessary functions.

Comprehension

  1. Who are the two user groups?
  2. Which requirements appear after prototype testing?
  3. What information does the database store?
  4. Why is the pilot useful?

Language focus — process sequence

Use:

  • First, ...
  • Next, ...
  • After that, ...
  • Before deployment, ...
  • Finally, ...

Darajali topshiriqlar

Beginner — A2

60–80 so‘zda oddiy web-ilovani tavsiflang: foydalanuvchi, muammo va uchta funksiya.

Intermediate — B1

100–140 so‘zda web-ilova yaratishning beshta bosqichini ketma-ket tushuntiring.

Advanced — B2

180–220 so‘zli product proposal yozing: problem, target user, requirements, technology, security va success measure.

Wiki writing

Propose a web application that solves a real student problem.

Talablar:

  • aniq foydalanuvchi va muammo;
  • kamida 5 ta modul termini;
  • 3–5 asosiy funksiya;
  • xavfsizlik yoki accessibility bo‘yicha bitta talab.

Peer-review

  • Muammo va foydalanuvchi aniqmi?
  • Funksiyalar muammoni hal qiladimi?
  • Jarayon tartibli tushuntirilganmi?
  • Taklifni sinash mumkinmi?

Self-assessment

  • Men frontend, backend va database farqini bilaman.
  • Men requirement yozishni tushunaman.
  • Men jarayonni ketma-ket ifodaladim.
  • Men taklifimni real ehtiyoj bilan bog‘ladim.
